# 电商模特图 Studio Demo 实施

目标：补齐已确认第一版的导入、引用、生成、回溯、入库和下载闭环。沿用 Node.js 与原生浏览器界面，按用户要求保持轻量。

- [x] `store.mjs`：SQLite 持久化资产、标签、对话和独立生成请求；图片存文件；从资产库移除不删原文件。
- [x] `provider.mjs`：支持 OpenAI Images 的 `/images/generations`、多参考图 `/images/edits`，以及 DashScope 原生多模态生成接口；解析 Base64 或 URL；任务异步运行，取消、重试、重启中断处理。
- [x] `server.mjs`：保留 API 设置，增加导入、标签、对话、生成、下载、服务期内分类记忆接口。
- [x] `index.html`、`studio.css`、`app.js`：可挤压聊天区的资产面板、任务列表、引用缩略图和可视化 @、比例、气泡及状态、右侧结果抽屉、大图详情、设置页。
- [x] 本机模拟服务闭环测试通过：导入与标签、多图请求、并行状态、入库、下载、取消、重试、重启持久化。实际浏览器检查当前窄窗口的页面与资产面板开合。不使用用户密钥做收费测试。

未验证：真实图片模型的效果与尺寸兼容性、所有桌面尺寸下的完整视觉回归。按轻量 Demo 范围保留为后续实际试用验收。

边界：当前支持 OpenAI Images 同步返回协议和 DashScope 原生同步返回协议，由本项目后端提供异步任务状态；不兼容厂商私有异步任务轮询接口。界面取消后停止本地等待，不能保证上游服务停止计费。图片效果依赖实际所选模型。
