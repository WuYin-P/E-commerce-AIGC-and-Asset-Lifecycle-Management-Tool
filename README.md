# 电商模特图 Studio Demo

需要 Node.js 22.13 或更新版本。

```sh
npm install
npm start
```

访问 http://127.0.0.1:64220 。已接入分类导入、资产多标签和单标签筛选、引用缩略图与结构化 @、比例选择、任务时间线、并行单图生成、取消和重试、全部结果抽屉、大图溯源、结果入库与原图下载。资产、标签和任务保存在 SQLite，原图和缩略图保存在本地。移出资产库不会删除历史引用或原图。

OpenAI 兼容服务的 API Base URL 包含服务的版本前缀，例如 `https://example.com/v1`，测试连接调用 `/models`，不生成图片。服务类型现在有 OpenAI 兼容、阿里云 DashScope 原生和自定义。DashScope 原生需要填写完整的 `/api/v1/services/aigc/multimodal-generation/generation` 地址，使用 `input.messages` 发送文字和最多 3 张参考图（单张 10 MB），从 `output.choices[0].message.content[].image` 读取结果；地址、Key 与模型必须属于同一地域和业务空间，配置检查不会调用模型。OpenAI 兼容仍按 `/images/generations` / `/images/edits` 处理。

自定义服务支持直接编辑请求方法、JSON 或 multipart 请求体、请求头变量、图片编码、参考图限制、尺寸分隔符和返回图片字段路径。可使用 `{{model}}`、`{{prompt}}`、`{{images}}`、`{{content}}`、`{{size}}`、`{{apiKey}}`；不执行用户脚本。自定义的「检查配置」只做本地格式验证，任务 ID 轮询类协议暂不支持。

每次请求一张图片，最多同时执行两次请求，其余排队。当前已适配阿里云 DashScope `qwen-image-3.0-pro`：比例菜单旁提供“1K/2K”常用尺寸，界面、任务记录和详情只显示档位名称；后端仍按当前比例将对应的实际像素尺寸通过官方 `parameters.size`（宽*高）发送。其它服务暂时只显示默认尺寸，不猜测其能力。取消会停止本地等待，但不能保证上游停止计费。服务重启会将未完成任务标记为中断，用户可手动重试。真实生成效果和服务兼容性需要使用客户选择的模型验收。

生成默认持续等待，不设置三分钟截止时间。从实际开始执行起等待满三分钟，卡片提示「仍在等待」并开放重试。重试在时间线下方创建关联记录，原卡片显示「已重新发送 · 查看重试任务」，新卡片可跳回原记录；重复点击原卡片不会重复发送。原请求继续接收和保存图片，重试请求单独计费并遵循原有并发上限。连接断开时显示「结果未知」，不将其当作上游生成失败；当前同步接口不能在断线后找回上游结果。

`npm test` 使用隔离临时目录和本机模拟服务检查主要闭环，不读取用户设置、不调用收费接口。备份时停止服务并复制整个 `data/`。默认数据目录可用 `STUDIO_DATA_DIR` 修改。

配置保存在本地 `data/api-settings.json`，文件权限为仅当前用户可读写，包含 API Key，请勿分享或提交。浏览器只接收密钥是否已保存的状态，留空保留现有密钥，修改地址时不会沿用旧服务的密钥。当前服务仅监听本机。

本版不包含账号或访问控制，不要直接暴露到公网。局域网部署可设置 `STUDIO_HOST` 与 `PORT`，应由交付方配置可信网络访问边界。
